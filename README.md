# daiwa-calendar-demo

工程表・勤務予定のスマホ版 UI デモ（モック／ダミーデータのみ）。

スマホで開くと画面いっぱいにモバイル UI が表示されます。画面の切り替えは、上部バーの「ふりがな」ボタン左のセレクタから。

- ① ホーム：所属現場の工程表
- ② 現場詳細：工程表
- ③ 配属現場一覧：勤務予定
- ④ 重機・点検一覧：予約
- ⑤ 出退勤一覧：休暇・欠勤カレンダー

Demo: https://katsu-lab.github.io/daiwa-calendar-demo/
（`#home` `#koutei` `#assign` `#res` `#cal` を付けると特定の画面を直接開けます）
